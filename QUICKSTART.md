# Quick start

```sh
npm ci
npm run dev
```

Requires Node.js 22.12+. Open the URL reported by Vite. Edit `src/data/portfolio.js` for portfolio content and `src/App.css` for styling. Replace `public/Aditya_Anil_Raut_resume.pdf` to update all résumé actions.

```sh
npm run sync:repos
npm run build
npm run preview
```

Push reviewed changes to `main` to publish through GitHub Actions. See [README.md](README.md) and [DEPLOYMENT.md](DEPLOYMENT.md).
