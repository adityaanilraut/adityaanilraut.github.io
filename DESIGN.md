# Design and content decisions

The portfolio uses a warm paper background, forest green accents, Manrope headings, DM Sans body text, and IBM Plex Mono for technical details. The emphasis is on readable hierarchy, restrained illustrations, and evidence rather than a long tool inventory.

The opening establishes the candidate's name, backend/AI focus, location, experience, résumé, and production impact. Selected work comes next, with CoderAI as the flagship, six complementary projects, and expandable engineering notes explaining problem, implementation, and evidence. Professional experience is aligned with the new résumé. Contact uses the current personal email address and LinkedIn profile.

CSS illustrations communicate architecture without stock imagery, large image downloads, or continuous animations. Project filters and repository search help technical reviewers inspect relevant work. Repository snapshots preserve content during API outages. The production page is prerendered for immediate content and discoverability.

Accessibility includes semantic landmarks and headings, a skip link, visible keyboard focus, real anchors, button state announcements, labeled repository controls, native disclosures, a mobile navigation button with expanded state and Escape handling, reduced-motion support, and a print stylesheet. Decorative graphics are hidden from assistive technology where appropriate.

Social metadata includes a 1200 × 630 PNG, canonical URL, description, ProfilePage/Person structured data, sitemap, and robots file. Search ranking or recruiter response is not guaranteed.
